## Design Claim Verified

The design asserted that no middleware is needed because `ReviewerContext` already carries `level`
and because middleware cannot see the target Cover. Implementation confirmed both:

- `reviewer.level` was available at each call site with no plumbing.
- The gate needs a database read (`covers → enrolls`) to know the target year, which middleware
  cannot perform before routing.

The design also reduced "DOED **and** ODPC" to `level === "ODPC"`, since `adminReviewerContext`
models a DOED admin as a national ODPC. Confirmed by test: the admin context passes the gate on a
closed year with no admin-specific branch anywhere in the code.
