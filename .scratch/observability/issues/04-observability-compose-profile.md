# 04 — `observability` Compose profile: Alloy, Loki, Tempo, Prometheus, Grafana, node_exporter

Status: ready-for-agent
Category: enhancement

## Agent Brief

**Category:** enhancement
**Summary:** Add an opt-in `observability` Compose profile that collects container logs, receives traces and scrapes metrics, with the agreed retention and Grafana reachable only on localhost.

**Current behavior:**
No monitoring services exist. Containers log JSON to stdout, and it is only reachable with
`docker logs`.

**Desired behavior:**
New services, all under `profiles: [observability]` only, each with an exact image version and a
named volume where it stores data:

| Service | Role | Exposure |
|---|---|---|
| `alloy` | Tails Docker container logs and ships them to Loki. Receives OTLP traces (HTTP 4318) and forwards them to Tempo. | Docker network only |
| `loki` | Log storage, **90-day** retention (`retention_period: 2160h`, compactor retention enabled) | Docker network only |
| `tempo` | Trace storage, **7-day** retention (`block_retention: 168h`) | Docker network only |
| `prometheus` | Scrapes metrics, **30-day** retention (`--storage.tsdb.retention.time=30d`) | Docker network only |
| `grafana` | UI, alerting | **`127.0.0.1:3001:3000` only** |
| `node-exporter` | Host CPU, RAM, disk | Docker network only (host `/` mounted read-only) |

- **Alloy log pipeline:** discover containers of this Compose project and label streams with
  `service` (Compose service name) and `env`. Parse the JSON `time` field (ISO + offset from issue 02)
  as the log timestamp, and promote `level` to a label. Keep `trace_id` in the line, not as a label,
  to avoid high cardinality. The Docker socket is mounted **read-only**. This is root-equivalent
  access for Alloy; record that trade-off in `docs/deployment.md`.
- **Alloy trace pipeline, defense in depth for decision 5:** delete span attributes matching
  `http.request.header.*`, `http.response.header.set-cookie`, `http.request.cookie`, `url.query` and
  `url.full` before export to Tempo, even though issue 05 never sets them.
- **Prometheus scrape targets:** API `:9464`, worker `:9464` (issue 07), `node-exporter`, and MinIO's
  `/minio/v2/metrics/cluster`, authenticated per MinIO docs with credentials from env, not the repo.
  Scrape interval 15 s.
- **Grafana:** data sources for Loki, Tempo and Prometheus, provisioned from files in the repo.
  Tempo↔Loki linking is by `trace_id`: a derived field in Loki, and trace-to-logs in Tempo.
  Anonymous access off, sign-up off, admin password from env. Dashboards and alerts come in issue 08.
- Config files live under one repo directory, e.g. `observability/`.
- **Secrets file:** the stack reads secrets from a new `observability.env`, never from `docker.env`,
  so app containers never see the Discord webhook or Grafana admin password. Add
  `observability.env` to `.gitignore` and commit an `observability.env.example` listing every key
  with placeholder values.
- **App wiring:** `api`, `api-dev`, `worker` and `worker-dev` get `OTEL_EXPORTER_OTLP_ENDPOINT` and
  `DEPLOYMENT_ENV` from `docker.env` or the `environment:` block. With the profile off, the endpoint
  is unset or unreachable and the app must still work (issue 05 guarantees this).
- `docs/deployment.md` gains an "Observability" section: the profile, ports, volumes, the env files,
  retention, the SSH-tunnel access command, and how to start dev/staging with the profile.

**Key interfaces:**
- `docker-compose.yaml` services and volumes.
- `observability/` configuration directory (Alloy, Loki, Tempo, Prometheus, Grafana provisioning).
- `observability.env.example`.

**Acceptance criteria:**
- [ ] `docker compose --profile dev up` starts **none** of the new services.
- [ ] `docker compose --profile dev --profile observability up -d` starts all six, and each is healthy
      or running.
- [ ] `docker compose config` shows Grafana published only on `127.0.0.1:3001`, and no other new
      service publishes a port.
- [ ] In Grafana (via `localhost:3001`), Explore → Loki shows `api-dev` log lines with the
      timestamp from the JSON field.
- [ ] Explore → Prometheus shows `up` for `node-exporter` and MinIO. API and worker targets exist
      and turn green once issue 07 lands.
- [ ] The retention settings above are visible in the committed config files.
- [ ] `git check-ignore observability.env` succeeds.

**Out of scope:**
- Dashboards and alert rules (issue 08).
- App-side instrumentation (issues 05–07).
- Any nginx change, or any public route to Grafana.
- `cAdvisor`, `postgres_exporter`, `redis_exporter`.
- Deploying to production (issue 09).
