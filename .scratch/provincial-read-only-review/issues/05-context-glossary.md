# 05 — CONTEXT.md glossary for provincial read access

Status: ready-for-agent
Category: enhancement
Depends on: 01, 02, 03, 04

## Agent Brief

**Category:** enhancement
**Summary:** Record the provincial read-only review vocabulary in `CONTEXT.md`.

**Current behavior:**
`CONTEXT.md` defines Staff Account, Cover, Score, Score Report, Grade and Verdict Score, and states
that a Provincial account sees one province. It says nothing about what a Provincial Officer may read
inside a Cover, and it has no term for the redaction of an open review.

**Desired behavior:**
`CONTEXT.md` gains the vocabulary settled during triage. `CONTEXT.md` is a glossary — describe the
domain rules, never the implementation.

Terms to capture:

- **Provincial Officer** as an observer role: reads every Cover in one province, writes nothing,
  never records a Verdict Score, never finalizes.
- The rule that an open review is confidential to the Officer: while a Cover is `in_review`, the
  Officer sees the factory's Answers, evidence and standard certificates, but no Verdict Score, no
  verdict description and no per-Answer status. When the Cover becomes `finished`, the Verdict Scores
  become visible, consistent with the Grade the Officer can already retrieve from a Score Report.
- The rule that a Cover in `in_progress` is not visible to the Officer at all — it is the factory's
  draft.
- Update the visibility table so the Provincial Officer's row covers the cover-review read, not only
  the Score Report.

**Acceptance criteria:**
- [ ] `CONTEXT.md` defines the Provincial Officer's read scope and its read-only nature.
- [ ] `CONTEXT.md` states the `in_review` confidentiality rule and the `finished` reveal.
- [ ] `CONTEXT.md` states that `in_progress` Covers are invisible to the Officer.
- [ ] No implementation detail appears — no route paths, no type names, no function names.
- [ ] Existing glossary terms are linked in the established `[[term]]` style.

**Out of scope:**
- An ADR. The trade-offs here are reversible and follow the existing region-scoping pattern; nothing
  warrants one unless the reviewer disagrees.
- Rewriting unrelated glossary entries.
